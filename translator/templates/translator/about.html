About TenaTalk

Empowering communication across Ethiopian languages with cutting-edge AI technology

Our Mission

TenaTalk is dedicated to breaking down language barriers in Ethiopia and beyond. We believe that everyone deserves access to clear, accurate communication regardless of the language they speak.

Our platform leverages Google Cloud's advanced AI technologies to provide real-time speech translation, helping healthcare providers, educators, businesses, and individuals communicate effectively across language boundaries.

Technology Stack

Built with cutting-edge technologies for optimal performance

Backend

  • Python 3.10+
  • Django 5.x Framework
  • Google Cloud Speech-to-Text API
  • Google Cloud Text-to-Speech API
  • Google Cloud Translate API
  • Meta MMS TTS for Oromo
  • Edge-TTS for Somali

Frontend

  • HTML5 & CSS3
  • Bootstrap 5
  • JavaScript (ES6+)
  • Django Template Language
  • Font Awesome Icons
  • Responsive Design

Key Features

Everything you need for seamless translation

Browser Audio Recording

Record speech directly in your web browser without any additional software. High-quality audio capture for accurate translations.

STT → Translate → TTS Pipeline

Seamless conversion from speech to text, translation, and back to speech in the target language.

Multi-Language Support

Support for Amharic, Somali, Oromo, Tigrinya, and English with accurate translations.

Fast Response Times

Lightning-fast translation powered by Google Cloud APIs. Get results in seconds.

Instant Audio Playback

Listen to translated speech immediately with adjustable voice and speed settings.

Clean & Responsive UI

Modern interface built with Bootstrap, working seamlessly across all devices.
